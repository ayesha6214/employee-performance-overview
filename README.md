# 📊 Employee Performance Analytics Dashboard

## 📌 Project Overview

The **Employee Performance Analytics Dashboard** is an interactive Power BI dashboard designed to analyze employee data, monitor workforce performance, and gain valuable insights into organizational growth.

This dashboard provides a comprehensive overview of employee statistics, salary distribution, performance ratings, departmental analysis, and employee joining trends through visually appealing charts and interactive filters.

## 🎯 Key Features

- **Total Employees:** Displays the overall number of employees.
- **Average Salary:** Shows the average salary across the organization.
- **Highest Salary:** Highlights the maximum employee salary.
- **Average Rating:** Displays the average employee performance rating.
- **Department-wise Employee Analysis:** Visualizes employee distribution across different departments.
- **Performance Distribution:** Categorizes employees into High, Average, and Low performance levels.
- **Average Salary by Department:** Compares average salaries across departments.
- **Employee Joining Trend:** Tracks employee joining patterns from 2018 to 2024.

## 🎛️ Interactive Filters (Slicers)

The dashboard includes interactive filters to analyze employee data based on:

- Department
- Performance
- Year
- Gender

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Visualization
- Data Analytics

## 📈 Dashboard Insights

This dashboard helps HR professionals and management teams to:

- Monitor overall workforce performance.
- Analyze employee distribution across departments.
- Compare departmental salary structures.
- Identify high-performing and low-performing employees.
- Track employee hiring and joining trends.
- Make data-driven HR and business decisions.
